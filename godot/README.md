# NOVA Movement Lab

This folder contains the first Godot 4 vertical-slice milestone for NOVA.

## Requirements

- Godot 4.3 or newer

## Run

1. Open Godot.
2. Import `godot/project.godot`.
3. Press **F6** or **F5** to run the movement lab.

## Controls

- **WASD** — Move
- **Mouse** — Look
- **Space** — Jump / wall jump
- **Shift** — Dash
- **C or Ctrl** — Slide
- **R** — Restart
- **Esc** — Release/capture mouse

## Included systems

- Accelerated ground movement
- Air strafing
- Momentum-preserving jumps
- Sliding
- Ground and air dashing
- Wall running and wall jumping
- Dynamic field of view based on speed
- Procedurally assembled gray-box movement course

## Current milestone

The goal is to validate that moving around is fun before adding portals, weapons, enemies, or multiplayer.
